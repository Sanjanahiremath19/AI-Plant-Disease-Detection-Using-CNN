# 🌿 AI Plant Disease Detection Using CNN

## Overview
This project uses Deep Learning with MobileNetV2 in MATLAB to detect and classify plant diseases from leaf images. The system predicts the disease, displays the confidence score, estimates disease severity, generates an AI heatmap, provides treatment recommendations, and offers an interactive graphical user interface (GUI) for easy use.

## Features
- 🌱 Plant disease classification
- 📊 Disease severity estimation
- 🎯 Confidence score prediction
- 🔥 AI heatmap visualization
- 💊 Treatment recommendations
- 🖥️ Interactive MATLAB GUI

## Technologies Used
- MATLAB
- MobileNetV2
- Deep Learning Toolbox
- Image Processing Toolbox

## Dataset
This project uses the **PlantVillage** dataset.

Download it from Kaggle:

https://www.kaggle.com/datasets/emmarex/plantdisease

After downloading, place the dataset inside a folder named `dataset`.

## How to Run

1. Download the PlantVillage dataset from Kaggle.
2. Place the dataset inside a folder named `dataset`.
3. Run `train.m` to train the MobileNetV2 model.
4. Run `gui.m` to launch the application.
5. Upload a plant leaf image and view the prediction results.
