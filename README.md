# 🌿 AI Plant Disease Detection Using CNN

## Overview
This project uses Deep Learning with MobileNetV2 in MATLAB to detect and classify plant diseases from leaf images. It provides disease prediction, confidence score, severity estimation, treatment recommendations, and an interactive graphical user interface (GUI).

## Features
- Plant disease classification
- Disease severity estimation
- Confidence score prediction
- AI heatmap visualization
- Treatment recommendations
- Interactive MATLAB GUI

## Technologies Used
- MATLAB
- MobileNetV2
- Deep Learning Toolbox
- Image Processing Toolbox

## Dataset
This project uses the **PlantVillage** dataset.

Download it from Kaggle:
https://www.kaggle.com/datasets/emmarex/plantdisease

## How to Run
1. Download the PlantVillage dataset from Kaggle.
2. Place the dataset inside a folder named `dataset`.
3. Run `train.m` to train the model.
4. Run `gui.m` to launch the application.
